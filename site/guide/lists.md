# Lists

You can keep as many lists as you like, for example a weekly shop, a barbecue and a hardware run. One list is the **active** list. It is the one the Shop tab shows, and every device sees the same active list.

## Switch lists

The list name at the top of the Shop tab opens a switcher. Pick another list to make it the active one.

## Create a list

1. Open the **Lists** tab.
2. Choose the new list button.
3. A sheet slides up from the bottom. Give the list a name and pick an icon.
4. Turn **Private** on if only you should see it, then choose **Create**.

## Private and shared lists

A list is shared with the whole household unless you mark it **Private**. A private list belongs to the person who made it. The owner, and Home Assistant administrators, can choose who else may see it.

## Change a list

Each list has a three-dot menu:

| Action | What it does |
|---|---|
| Rename | Change the name. |
| Manage members | Choose who can see a private list. Only appears for private lists you own, or if you are an administrator. |
| Copy | Make a copy of the list. |
| Delete | Remove the list and its items. |

## Share a list as text

Open the list options (the sliders button in Fresh, or the menu in Compact) and choose **Share list**. The list is copied to the clipboard, or opens the share sheet on a phone.

## Link a list to a Home Assistant to-do list

Under **Settings → HA Todo Sync** you can link a list to a Home Assistant to-do list. Adding, ticking and removing items is mirrored both ways. It only syncs while the linked list is the active list.
